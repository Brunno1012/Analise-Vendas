# Analise-Vendas
# 📊 Previsão de Vendas com Machine Learning

Projeto de análise e previsão de vendas utilizando bibliotecas de ciência de dados em Python. A ideia foi aplicar técnicas de modelagem preditiva para estimar o volume de vendas com base em dados históricos e variáveis relevantes de mercado.

## 🚀 Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Plotly Express
- Scikit-learn (Random Forest e Regressão Linear)

## 📌 Objetivo

Realizar uma análise exploratória dos dados, identificar padrões de comportamento nas vendas e construir modelos de machine learning para prever futuros resultados com base nas variáveis fornecidas.

## 🔎 Etapas do projeto

1. **Importação e preparação dos dados**
2. **Análise exploratória (EDA)**
   - Gráficos interativos
   - Correlações
3. **Tratamento de dados faltantes e conversão de variáveis**
4. **Criação de modelos preditivos**
   - Random Forest Regressor
   - Regressão Linear
5. **Avaliação dos modelos**
   - Erro Absoluto Médio (MAE)

## 📈 Resultados

Os modelos foram avaliados com base em suas previsões e desempenho. A Random Forest obteve melhor desempenho em comparação à Regressão Linear, apresentando menor erro na previsão de vendas.
